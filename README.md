# ClearAir — Smog-aware living

A lightweight responsive prototype of a GenAI-ready assistant for families navigating winter smog and urban air pollution.

## Prototype features
- City context (sample Kolkata demo)
- AQI panel clearly marked as a sample, not live data
- Action cards for indoor air, travel, cooking, dust and community habits
- Impact explanations with caveats
- Interactive daily checklist
- Responsive layout

## Preview
Open `index.html` in a browser. No build tools required.

## Next iteration
Connect a live AQI/weather API, add city selection, and add an AI backend using a server-side API key. Do not expose keys in client-side code.

## Safety
This prototype is educational, not medical advice. AQI is mock data and must be replaced by a reliable data source before deployment.
